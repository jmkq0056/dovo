Features

Built for vibecoders.

Every feature exists because clicking through menus for Claude Code workflows got annoying. None of it pretends to be AI; it makes the CLI feel like part of the IDE.

Claude Reader v1.2

When claude runs, the conversation reads like a chat: your messages as bubbles, tool steps folded, diffs as cards, images Claude read as thumbnails. Claude's live output streams in as it writes, a "Now" line says what it's doing ("Editing app.ts · 14s"), and the prompt rail with fuzzy search jumps to any earlier prompt.

Focus and IDE layouts v1.2

Claude takes the window by itself; a file you open lands on the right half. Press ⌘B for the IDE layout: file tree left, file on top, Claude below. Switch between Reader and plain Terminal with one click.

Queue and send now v1.2

Messages you type while Claude works show up queued, exactly as Claude sees them. Ctrl ↵ sends one right away. Esc shows a clear "interrupted" mark, and Larger Input gives long prompts and Claude's menus room to read.

Background shells and agents v1.2

The Activity panel lists every command Claude runs in the background and every agent it starts, live. Read a shell's output or stop it, and open an agent to read its own conversation.

True context meter v1.2

The header shows how much of Claude's context is used, read from the session itself and matching /context, 1M windows included. Nothing is typed into Claude to get it.

Project dock v1.2

Every project one click away at the top of the activity bar, each in its own window. A dot shows its Claude: pulsing while it works, green when it's waiting for you.

Tabs that tidy themselves v1.2

At most eight tabs, and files you haven't looked at for 20 minutes close by themselves (with a Reopen). Images Claude shows open as previews, never piling up. Claude's terminal is never closed.

Image previews v1.1

Every [Image #N] gets a numbered thumbnail right at it, a large hover preview and cmd-click to open. Image paths and file:// links too. Works before you send the prompt, and in Claude's fullscreen mode.

Smart auto-launch

Open a project and your last Claude session resumes by itself, and only in project folders, never your home folder. Numbered 1 -- MAUT with its own icon and color per session.

Type maut anywhere

Type those four letters in the editor, search or command palette: the keystrokes are removed and a fresh Claude terminal spawns. In terminals and the Reader, "maut" is just text.

Drag as @-mention

Drag files and folders, from anywhere in the tree, onto Claude and each becomes @workspace/path, in the terminal or the Reader. Drag an editor selection for @path:start-end.

Undo Claude's edits

The Maut Activity sidebar lists every file Claude touched this session. Click for the diff; right-click to undo per file or per edit, with redo.

PDF page picker

Right-click a PDF and pick pages visually or type a range like 3-15, 20. The extract lands in ~/.maut-tmp/ and is @-mentioned into the CLI.

Markdown that reads well

.md opens as a real preview with a sticky table of contents and highlighted code. ⇧⌘V toggles to source.

Right-click servers

Right-click a folder: Maut detects Node, Python, Rust, Go, Make or Docker and starts the right command in a terminal.

Word, Excel, PowerPoint

Click an Office file to hand it to its app. Right-click to convert to TXT, JSON or PDF. No more "file is binary" warnings.

Focus mode

⌘K ⌘M takes the active file or terminal full width; press again to restore your layout exactly.

One-click commit

A status-bar button stages everything, commits with your message and optionally pushes, all in quick-pick UI.

One-click fetch and pull

Pick a remote and branch to fetch and pull. On a conflict, choose stash and pull, reset, or cancel.

Theme Studio

Set accent, surface tone, font and size for light and dark separately; ⇧⌘L swaps between them. The font applies to the whole workbench, not just the editor.

Install

One command. Run it again to update.

Each installer fetches the latest release, puts Maut where your system expects apps, and opens it.

macOS Apple Silicon

$curl -fsSL https://jmkq0056.github.io/maut-code/install.sh | bash

Installs into /Applications (an older copy goes to the Trash), clears the quarantine flag so macOS opens it without the right-click dance, and offers to install Claude Code.

Windows x64 · PowerShell

>irm https://jmkq0056.github.io/maut-code/install.ps1 | iex

Installs for your user with no admin rights and no wizard; adds Start menu and desktop shortcuts, Explorer's right-click menu and maut-code on your PATH; offers to install Claude Code.

Prefer a download?

The buttons at the top get the same builds. On macOS, open the .dmg, drag Maut code to Applications, then right-click it and choose Open the first time (it's ad-hoc signed, not notarized). On Windows, download Maut-code-Setup-x64.exe and run it: it installs for your user, no admin rights needed. It isn't code-signed yet, so SmartScreen may ask you to choose More info, then Run anyway. Windows 11 with Smart App Control on, or a work PC with an app-control policy, blocks unsigned apps entirely; there, Maut can't install until it's signed. A portable Maut-code-win-x64.zip is on every release too.
