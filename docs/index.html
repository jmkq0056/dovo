Code with Claude,
not around it.

Maut code is a fork of VS Code with Claude Code CLI baked into the IDE. Auto-resume your last session on launch, drag files into the terminal as @-mentions, undo Claude's edits per file, render markdown beautifully — and more.

Built for vibecoders.

Every feature exists because clicking through menus for Claude Code workflows got annoying. None of it pretends to be AI; it just makes the CLI feel like part of the IDE.

⚡

Smart auto-launch

Open Maut and your last Claude session resumes in a fresh terminal automatically. Numbered 1 -- MAUT with a unique icon and color per session.

⌨️

Type maut anywhere

Type those four letters in sequence anywhere in the window — your keystrokes are removed and a fresh Claude terminal spawns. Works in the editor, search, palette, even another terminal.

@

Drag-as-@-mention

Drag any file from the explorer into a Maut terminal → it becomes @workspace/path. Drag an editor text selection → @path:start-end. Inline ⌀ button on every row for one-click adds.

↶

Undo Claude's edits

The Maut Activity sidebar lists every file Claude touched this session. Click → diff. Right-click → undo, per file or per edit. Even per-action redo.

🖼

Image previews on hover

[Image #N] in the terminal is cmd-clickable and shows a 480 px hover preview pulled live from ~/.claude/image-cache/.

📄

PDF page picker

Right-click any PDF → pick pages visually or type a range like 3-15, 20, 22-25. Extracted PDF lands in ~/.maut-tmp/ and gets @-mention'd into the CLI.

🌒

Custom markdown render

.md opens as a real HTML preview with sticky TOC, code syntax via highlight.js, JetBrains Mono. ⇧⌘V toggles to source.

🚀

Right-click servers

Right-click any folder → detects Node / Python / Rust / Go / Make / Docker setups and starts the right command in a Maut terminal.

📎

Docx / Xlsx / Pptx

Click an Office file → auto-handoff to Word / Excel / PowerPoint. Right-click → convert to TXT / JSON / PDF. No more "file is binary" warnings.

🎯

Focus mode

⌘K ⌘M zens the active file or terminal full-width; second press restores your layout exactly.

🗳

One-click commit

Bottom-right status-bar button stages everything, commits with a typed message, optionally pushes to origin — all VS Code quick-pick UI, no macOS dialogs.

⬇️

One-click fetch + pull v1.0.5

Companion to the commit button. Pick remote → branch → fetch+pull. If it conflicts, a quick-pick offers stash & pull, reset --hard, or cancel.

🎨

Theme Studio v1.0.6

Opens as a sidebar view next to Maut Activity. Configure Light and Dark independently — accent, surface tone, font family, font size — and ⇧⌘L swaps between your two saved configs. Font choice cascades to the whole workbench UI (sidebar, tabs, menus), not just the editor.

Install on macOS

Maut is ad-hoc signed, not notarized — so macOS will scare-warn the first time. Right-click the app, hit Open. Once.

1. Get Claude Code

Maut wraps Anthropic's Claude Code CLI. Install it first:

$ npm install -g @anthropic-ai/claude-code
# or: brew install claude
$ claude login

2. Install Maut code

  1. Download the .dmg from the button above.
  2. Open the DMG, drag Maut code.app to /Applications.
  3. Right-click Maut code.app → Open → confirm.
  4. That's it — open Maut, your last Claude session auto-resumes.

Windows

Download Maut-code-Setup-x64.exe and run it. It installs for your user only, so no admin rights are needed, and adds Maut code to the Start menu. The installer isn't code-signed yet, so SmartScreen may warn on first run: click More info → Run anyway. Prefer no installer? Each release also has a portable Maut-code-win-x64.zip: unzip it and run Maut code.exe.
